# 03 - In-Session Workflow

Use this from 9:25 AM to 11:30 AM ET only.

## Hard Time Rule

No new trades after 11:30 AM. If already in a trade, manage it. If flat, the day is done.

## Before The Session

Confirm:

```text
Premarket file completed: Y/N
Priority instrument chosen: ES / NQ
Top two levels identified: Y/N
No-trade conditions written: Y/N
Daily loss rule reset: Y/N
Screenshot folder created: Y/N
```

## 10-Second Trade Gate

Answer all questions before placing size:

1. Is this at a valid location from the premarket map?
2. What is the location grade: A / B / C / F?
3. What is the current regime: balance / compression / expansion / trend / slow grind / unclear?
4. Is this the right model for that regime?
5. Is 5-minute footprint volume above 20K?
6. Is 9:30 footprint volume above 10K if this is early-session?
7. Is delta loud but ineffective, or efficient and accepting?
8. Is Delta Effort rising or falling?
9. Is Delta NT expanding or stalling?
10. Who is trapped?
11. Who is being rewarded?
12. What must happen quickly if this is valid?
13. Am I trading the setup, or am I forcing bias/action?

If any answer is unclear, do not enter. C-grade and F-grade locations are observation only unless the rulebook is later updated with validated exceptions.

## Fabio/Carmine Battle-Test Add-On

Use this when the trade is tempting but the market is messy:

```text
Current regime: balance / compression / expansion / trend / slow grind / unclear
Cage status: inside / edge / clean break / failed break / accepted outside
Who is trapped:
Who is being rewarded:
Is aggression getting paid: Y/N/unclear
Is this at the edge or in the middle:
Would this be easy to journal immediately: Y/N
Same-thesis losses today:
```

Rules:

- Inside the cage, trade only edges or do nothing.
- If aggression is loud but not getting paid, wait for reclaim or rejection.
- If the same thesis has failed three times, shut that thesis down.
- If the setup needs to work fast and tape is dead, skip or scratch according to plan.
- If execution environment is slow, reduce size or skip fast-trigger setups.

## In-Trade Management

Protect the original plan:

- If stop is hit, exit immediately.
- Do not add to a loser.
- If trade reaches planned breakeven rule, move to breakeven only if the setup rules called for it before entry.
- Do not widen stop because the market "should" turn.
- If absorption appears at target, respect it.
- If delta flips against your position, reassess and follow exit plan.
