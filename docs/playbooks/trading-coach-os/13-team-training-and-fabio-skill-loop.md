# 13 - Team Training And Fabio Skill Loop

## Purpose

This repo is being built with a day-trading team so the Hermes Fabio ES/NQ coach can learn the team's real language, screenshots, market prep, setup definitions, and feedback.

The goal is not to create a signal bot. The goal is to help each trader become better faster by turning every day into structured evidence:

- better pre-market planning
- clearer key levels
- stronger setup filtering
- Fabio-style terminology
- weighted confirmation signals
- screenshot-based review
- personalized coaching
- better patience and risk discipline

## Core Thesis

A trader improves faster when the coach can see:

- what levels mattered before the trade
- what the trader thought before the trade
- what the screenshot showed at the decision point
- which confirmation signals were present
- which signals mattered most
- what Fabio/team language applies
- what the trader did emotionally and behaviorally
- what should change tomorrow

Hermes plus SuperGrok/x_search can add outside context and market narrative, but the strongest training data is still the team's own screenshots, levels, journals, and review notes.

## Weighted Confirmation Model

Not all signals are equal. The coach should learn which signals Fabio and the team weight most.

Default weighting:

| Signal | Default Weight | Notes |
| --- | ---: | --- |
| Location at key level | 5 | No meaningful location usually means no trade. |
| Regime fit | 5 | Balance, compression, trend, expansion, and slow grind need different playbooks. |
| Effort vs result | 5 | Aggression getting paid vs absorbed is core. |
| Trapped participants | 4 | Stronger when the pain is obvious. |
| Volume / participation | 4 | Volume gates protect from dead tape. |
| Delta / Delta Effort / Delta NT | 4 | Useful only when interpreted at the right level. |
| Room to target | 4 | No 15+ points of juice means skip. |
| Pre-market thesis alignment | 3 | Exceptions need extra evidence. |
| Screenshot clarity | 3 | If it cannot be journaled, it is probably not clean. |
| Trader state | blocker | Revenge, boredom, or rule danger overrides setup quality. |

The team should adjust these weights after real examples.

## Screenshot Training Standard

Each screenshot should help answer:

- Where is price relative to the key level?
- Is this edge, middle, breakout, failed break, reclaim, reload, or chop?
- What is the regime?
- Is aggression getting paid?
- Who is trapped?
- Is the target path clean?
- Would Fabio call this a setup, a wait, or a no-trade?

## SuperGrok / x_search Role

Use SuperGrok/x_search for:

- X posts and articles from high-signal traders.
- Fabio/team terminology research when available.
- Market-moving narrative checks.
- Post-session context.
- Broader order-flow education examples.

Do not use X chatter as a trade trigger. Social context is supporting evidence, never the reason for risk.

## Public Output Standard

Before anything graduates to a free tips channel, it must be:

- educational
- evidence-backed
- clear about risk
- not a blind signal
- reviewed by humans
- consistent with the rulebook
- valuable even if the viewer does not take a trade
