# Fabio Pre-Market Sentiment

Use before a trading session.

## Output

```text
Session:
Market Context:
Important Numbers:
Catalysts:
Key Levels:
No-Trade Conditions:
Setup Watchlist:
Scout -> Setup Copilot Message:
```

## Rules

- Use the ubiquitous language dictionary.
- Compress raw data.
- Do not invent live data.
- Do not tell the trader to enter.
- If source quality is weak, say so.
