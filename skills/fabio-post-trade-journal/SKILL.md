# Fabio Post-Trade Journal

Use after a trade or session.

## Output

```text
Setup:
Decision Quality:
Rule Followed/Broken:
Mistake Pattern:
Lesson:
Memory Candidate:
Skill Update:
Next Session Reminder:
```

## Rules

- Be honest and evidence-first.
- Do not shame the trader.
- Do not store private account details.
- Save only repeatable, reviewed lessons as memory candidates.
