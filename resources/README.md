# Shared learning resources

Store only sanitized material intended for the team. Private trading logs and original account screenshots remain at `~/TradingCoachLogs/YYYY-MM-DD/` outside Git.

Add reviewed examples under `examples/`, sanitized screenshots under `screenshots/`, concise sourced context under `market-notes/`, and sourced news summaries under `news/` when actual material is available. No examples or feeds were supplied in this consolidation.

Each addition should record source, date/time, instrument, observed evidence, interpretation, reviewer and whether it is a candidate or reviewed lesson. Use [training intake](../skills/fabio-screenshot-pattern-gate/references/training-intake.md) and [memory candidate format](../docs/memory/journal-memory-plan.md). Link additions from the resource index.
