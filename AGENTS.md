# Working in this repository

Start with README.md and docs/START-HERE.md. Use docs/RESOURCE-INDEX.md for targeted reading; do not load the entire repository during a live session.

- profiles/fabio-trading-copilot/SYSTEM.md defines the coaching identity; read its ubiquitous_language.md before coaching outputs.
- docs/playbooks/trading-coach-os/08-personal-rulebook.md owns the existing ES/NQ operating rules. Nested AGENTS.md applies in that playbook directory.
- skills/ owns task interfaces. docs/research/nq/ contains instrument-specific supporting material, not automatic amendments to the live rulebook.
- apps/ai-trading-coach/ is a separate Bitget historical-review application. Run its commands from that directory; preserve its source layout, license and configuration boundaries.
- No automated trade execution. Never fabricate market evidence or treat a design document as proof of an available integration.
- Keep private logs outside Git. Store only sanitized, reviewed learning in shared resources.
- Preserve provenance when importing material. Update docs/RESOURCE-INDEX.md and docs/STATUS.md when adding or relocating assets.
- The source manifest records the import baseline, not hashes to rewrite after subsequent intentional edits.
- For organization-only changes, verify local links, source preservation and git diff. Do not start schedulers, contact exchanges, or send Discord messages as a documentation check.
